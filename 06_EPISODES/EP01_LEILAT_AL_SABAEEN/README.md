# Episode 01 — ليلة السبعين

**Target runtime:** 10:00 minutes.  
**Scenes:** 5.  
**Location scope:** the Al-Shenawy mansion only.

## Production order
1. Read the self-contained episode script in `01_SCRIPT`.
2. Prepare and approve the three location masters and all required character/prop masters.
3. Complete each scene package with scene-specific keyframe prompts, start/end frames, shot prompts, voice lines, and continuity state.
4. Generate and review keyframes in `04_KEYFRAMES`.
5. Animate only approved keyframes into WAN clips in `05_VIDEO_RAW`.
6. Record/generate and lock audio in `06_AUDIO`.
7. Edit and export in `07_EDIT_PROJECT` and `08_EXPORTS`.
8. Complete quality control in `09_QC_AND_CONTINUITY`.

كل مشهد له مجلد مستقل. يجب أن يحتوي ملف Scene Package على مواصفات الشخصيات والموقع والملابس والإكسسوارات والحركة والحوار والصوت والـ Prompts الخاصة به. لا تكتفِ بإحالة إلى Bible آخر.
