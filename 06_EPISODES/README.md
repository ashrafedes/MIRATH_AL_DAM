# Episode Production Packages

Create one folder per episode. Include episode control, locked script, scene breakdown, self-contained scene folders, storyboard, keyframe manifest, video-generation manifest, audio manifest, edit notes, QC, and delivery record.

Each scene package must specify scene identity/script excerpt, dramatic purpose, time/location/lighting, characters/wardrobe/voice, props and states, blocking/eyelines/screen direction, shot-by-shot camera plan, dialogue/sound, prompts/settings, continuity bridges, and QC approval.
