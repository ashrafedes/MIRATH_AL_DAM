# File Naming Standard

استخدم أسماء إنجليزية ثابتة بلا مسافات، وأبقِ معرف الشخصية/الموقع/الإكسسوار ظاهرًا.

## أمثلة
- `CHAR_01_HUSSEIN_MASTER_v01_APPROVED.png`
- `LOC_01_MAIN_HALL_MASTER_v02_APPROVED.png`
- `PROP_P01_GLASS_INTACT_v01_APPROVED.png`
- `E01_SC01_SH001_KEYFRAME_v03.png`
- `E01_SC01_SH001_WAN_v02.mp4`
- `E01_SC01_HUSSEIN_DIALOGUE_TAKE02.wav`

## القواعد
1. لا تستخدم أسماء مثل `final_final2`.
2. ارفع رقم النسخة عند كل تغيير.
3. لا تستبدل ملفًا معتمدًا؛ أنشئ نسخة جديدة وسجّل سبب التغيير.
4. أضف `DRAFT`, `REVIEW`, أو `APPROVED` عند الحاجة.
5. احتفظ بالأصل المولد وبنسخة المعالجة منفصلين.
