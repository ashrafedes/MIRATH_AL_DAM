# Project Control — ميراث الدم

هذا المجلد هو نقطة إدارة المشروع. لا تحفظ فيه صور الإنتاج النهائية؛ احتفظ هنا بالفهارس والقرارات وسجلات الاستمرارية.

## الملفات
- `PROJECT_MANIFEST.md`: وصف بنية المشروع.
- `ASSET_REGISTER.csv`: سجل لكل شخصية/موقع/إكسسوار وحالة اعتماده.
- `CONTINUITY_LOG.md`: سجل تغييرات الوجوه والملابس والمواقع والإكسسوارات.
- `FILE_NAMING_STANDARD.md`: قواعد تسمية الملفات.

## حالات الاعتماد
- `DRAFT`: مسودة أولية.
- `REVIEW`: قيد المراجعة.
- `APPROVED`: مرجع معتمد للاستخدام في Keyframes وWAN.
- `REJECTED`: مرفوض ولا يستخدم في الإنتاج.
- `SUPERSEDED`: نسخة قديمة استبدلت بنسخة أحدث.

لا يتحول أي ملف إلى `APPROVED` لمجرد أنه تم توليده. يجب مراجعته بصريًا ومقارنته بالمرجع القانوني للشخصية/الموقع/الإكسسوار.
