# Naming Convention

Use stable IDs, uppercase ASCII, and underscores.

Pattern: `MAD_[EPISODE]_[SCENE]_[SHOT]_[ENTITY]_[ASSETTYPE]_v[VERSION]_[STATUS].[ext]`

Example: `MAD_EP01_SC003_SH012_CHAR_002_KEYFRAME_v01_APPROVED.png`

Never use dates instead of versions or names such as `final_final`. The asset register is authoritative.
