# LOC_02_LIBRARY — مكتبة حسين

الوظيفة: Lawyer meeting and the forty-day personal envelope.

- `00_CONCEPT_DRAFTS`: تصميمات أولية.
- `01_MASTER_APPROVED`: الصورة التأسيسية المعتمدة للموقع.
- `02_CAMERA_ANGLES`: زوايا الكاميرا مع ثبات هندسة المكان.
- `03_LIGHTING_VARIANTS`: نسخ الإضاءة حسب وقت المشهد، لا تغيّر تصميم الموقع.
- `04_SET_DRESSING`: الأثاث والديكور والإكسسوارات الثابتة.
- `05_CONTINUITY_MAP`: مخطط الاتجاهات ومواقع الأبواب والنوافذ والأثاث.
- `06_PRODUCTION_NOTES`: ملاحظات التنفيذ.

لا تعكس الصور أفقيًا؛ ثبّت مواضع الأبواب والنوافذ والمرآة والأثاث بين جميع الزوايا.
